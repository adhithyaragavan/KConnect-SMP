fork(): clones the current running process (child process)
exit(): terminates the process and cleans up its resources
exec(): replaces current process memory with a new program
getpid(): returns unique process id of the current running process
open(): opens a file or device returning the file descriptor
read(); used to read bytes of data from a file descriptor to a buffer
write(): used to write bytes of data from a buffer into a file descriptor
close(): closes open file descriptor
mmap(): maps files directly into a programs memory letting u read and write using fast operations using pointers instead of tradition read/write operations
